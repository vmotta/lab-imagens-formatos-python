# Como entregar a atividade

## Forma recomendada: fork e Pull Request

1. Faça um **fork** deste repositório.
2. Abra o notebook no Google Colab pelo seu fork.
3. No Colab, use **Arquivo → Salvar uma cópia no GitHub**.
4. Salve o arquivo com o nome:

   ```text
   entregas/SEU_USUARIO_GITHUB/laboratorio_formatos_imagens.ipynb
   ```

5. Abra um Pull Request para o repositório da turma.
6. No texto do Pull Request, informe:
   - nome completo;
   - integrantes da dupla, quando houver;
   - conclusão principal;
   - formato escolhido para fotografia web;
   - formato escolhido para logotipo transparente.

## Alternativa: Issue de entrega

Quando o professor optar por não receber Pull Requests, use o modelo **Entrega do laboratório** na aba Issues e informe o link da cópia do notebook.

## Regras

- Não altere o notebook original em `notebooks/`.
- Não envie as imagens geradas em `dados/` ou `resultados/`.
- Não envie arquivos ZIP.
- Mantenha as respostas nas células indicadas por **RESPOSTA**.
- Verifique se todas as células foram executadas antes da entrega.
