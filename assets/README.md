# Recursos visuais

Este diretório contém apenas um SVG versionado, pois ele é um formato textual.

As imagens rasterizadas usadas no laboratório são produzidas pelo script [`src/gerar_imagens_exemplo.py`](../src/gerar_imagens_exemplo.py). Essa decisão:

- mantém o repositório leve;
- garante que todos os estudantes trabalhem com as mesmas imagens;
- permite repetir o experimento;
- mostra que imagens podem ser criadas e processadas por código.

Arquivos gerados durante a execução:

- `foto_exemplo.png`: fotografia sintética com gradientes e texturas;
- `tela_exemplo.png`: interface com textos e linhas;
- `logo_transparente.png`: imagem RGBA com canal alpha;
- `icone_escalavel.svg`: cópia do exemplo vetorial.
